# Best Friend Memory Experience

A premium, mobile-first interactive website built with Next.js, Tailwind CSS, TypeScript, Framer Motion, GSAP, Lenis smooth scroll, and Canvas Confetti.

## Pages
- `/` — Password Gate
- `/letter` — The Letter Experience
- `/memories` — Memories Gallery

## Local Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000`

## Customization
- Password: `src/lib/constants.ts`
- Letter text: `src/lib/constants.ts`
- Gallery images: `public/images`
- Music track: `public/music/ambient.wav`
